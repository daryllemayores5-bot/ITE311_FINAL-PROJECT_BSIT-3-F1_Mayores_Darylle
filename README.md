## Project Description

The School Event Management System is a web-based application developed using Vue.js 3. It is designed to help school administrators and student organizers manage school events efficiently.

The system allows users to create, view, update, and delete school events. It also provides a dashboard that displays event statistics, including total events, upcoming events, ongoing events, and completed events.

## Features

- Add new school events
- View school event details
- Edit existing events
- Delete events
- Search and filter events
- Automatically calculate event statistics
- Save event records using browser localStorage

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local address displayed in the terminal.
